# 一手资料源清单 · Phase 1 三大文化体系

## 四、跨文化 / 通用监听源（用于自动扫描）

| 名称 | 类型 | 抓取方式 | 用途 |
|------|------|---------|------|
| **arXiv** (cs.CL, physics.hist-ph 少量) | 论文 | API | 主要抓 digital humanities 相关 |
| **DOAJ** (Directory of Open Access Journals) | 开放期刊索引 | API | 民俗学/宗教学开放期刊入口 |
| **CrossRef API** | DOI 元数据 | API | 关键词监听新论文 |
| **OpenAlex** | 学术图谱 | 免费 API | Google Scholar 的开放替代 |
| **Google Scholar Alerts** | 邮件订阅 | 邮件 → 解析 | 关键词自动通知 |
| **HathiTrust** | 数字图书馆 | API | 大量公版民俗学著作 |
| **Europeana** | 欧洲文化遗产 | API | 手稿、插画、民俗物件 |
| **Reddit r/mythology, r/folklore, r/AskHistorians** | 社区讨论 | RSS/API | 用于发现"民间正在讨论什么"，**不作为来源**，只作为线索 |
| **Atlas Obscura RSS** | 新闻 | RSS | 神秘地点/事件线索 |
| **Fortean Times** | 杂志 | RSS/官网 | 老牌"奇闻"专业刊，可作线索源 |
