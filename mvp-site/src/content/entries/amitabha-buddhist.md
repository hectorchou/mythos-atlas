# 阿弥陀佛 · 西方极乐世界与净土宗

## 一、名号与身份

**阿弥陀佛(Amitabha)** 梵名有两义:
- **Amitabha** 意为"**无量光**"—象征遍照十方
- **Amitayus** 意为"**无量寿**"—象征寿命无量

汉译**阿弥陀**是Amita音译,"佛"是Buddha简译。**无量寿佛、无量光佛**是两种意译。日语作**Amida**,是华语世界外最广泛的佛陀形象之一。

**Nattier (2003)** 考据阿弥陀信仰的印度贵霜时期(约1-3世纪)起源—与拜火教Ahura Mazda"智慧光"存在结构呼应的可能性。

## 二、法藏比丘的四十八大愿

**《无量寿经》**(康僧铠252年译,汉传佛教称"大本")完整叙述阿弥陀本生:
- 无央数劫前有**世自在王佛**住世
- 有国王闻法出家,号**法藏比丘**
- 于世自在王佛前发**四十八大愿**
- 若愿不实现,誓不成佛

**核心愿望**:
- **第十八愿**(核心)—十方众生至心信乐,乃至十念,愿生我国,若不生者不取正觉。
- 第十九愿—发菩提心修诸功德,愿生我国,临终佛与圣众来接
- 第二十愿—闻我名号,系念我国,回向愿生

法藏历经无量劫修行,终成**阿弥陀佛**,建立**西方极乐世界(Sukhavati)**—**净土宗信仰核心**。

## 三、西方极乐世界

**《阿弥陀经》**(鸠摩罗什402年译,"小本")描绘极乐世界:
- **七重栏楯、七重罗网、七重行树**皆四宝周匝
- **七宝池八功德水**,池底金沙布地
- 池中莲花大如车轮,青黄赤白光色
- **无三恶道**—无地狱、饿鬼、畜生
- **鸟鸣皆演佛法**—白鹤孔雀鹦鹉舍利伽陵频伽共命鸟
- **诸上善人俱会一处**

极乐世界是**宗教理想国**的具象化,与地狱十王形成完整宇宙论对比。**Wong (2001)** 论极乐世界与弥勒兜率天皆为汉传佛教理想乐土,但地位与功能不同。

## 四、汉传净土宗

**Nattier (2003)** 与 **Vojtíšek (2022)** 追溯净土宗历史:

**东汉初传(148-220)**
- **支娄迦谶** 译《般舟三昧经》—最早提及阿弥陀

**曹魏系统化(252)**
- **康僧铠**译《无量寿经》—奠基文本

**东晋建社(402)**
- **慧远大师**在庐山东林寺组织**"白莲社"** 123人共修念佛
- 净土宗初祖

**南北朝-唐(以下祖师)**
- **昙鸾**(476-542)—论《往生论注》
- **道绰**(562-645)—《安乐集》
- **善导**(613-681)—**净土宗集大成**,《观经四帖疏》系统化

**宋后禅净合流**
- **永明延寿**(904-975) 力倡"禅净双修"
- 明代**云栖袾宏**(1535-1615)进一步整合
- 净土宗成为汉传佛教最普及信仰

## 五、念佛法门

**净土宗核心修行**:
- **持名念佛**—口诵"**南无阿弥陀佛**"
- **观想念佛**—依《观经》十六观法
- **实相念佛**—禅净结合,念佛即观空

**六字洪名**:南无阿弥陀佛(Namo Amitabha)
- **南无(Namo)**—皈依
- **阿弥陀佛**—无量光/寿佛

普通信众只需**一心不乱**念诵,临终十念皆可**往生极乐**—这是**汉传佛教平民化**的最重要设计。

**Tan (1983)** 论马来西亚华人"家家阿弥陀"—念佛法门是华人临终关怀的核心。

## 六、九品往生

**《观无量寿经》**规定往生分**九品三级**:

| 品级 | 修行程度 | 往生形态 |
|------|---------|---------|
| **上品上生** | 圆解圆信,慈心不杀 | 佛来迎,金刚台 |
| **上品中生** | 深解义趣 | 紫金台 |
| **上品下生** | 亦信因果 | 金莲花 |
| **中品上生** | 五戒八戒 | 莲花开合七日闻法 |
| **中品中生** | 一日一夜八关斋 | 一劫成阿罗汉 |
| **中品下生** | 孝养父母 | 一小劫成阿罗汉 |
| **下品上生** | 造恶而遇善知识 | 十二大劫莲花开 |
| **下品中生** | 破戒偷僧物 | 六劫开花 |
| **下品下生** | 五逆十恶 | 十二大劫开花 |

即使**五逆十恶**罪人,临终十念也可往生下品下生—体现**净土宗的普世救度**特质。

## 七、图像学

**Attwood (2023)** 与相关研究:
- **单独像**—结**阿弥陀定印**(双手叠置腹前托宝钵)或**说法印**
- **西方三圣**—中央阿弥陀,左观音,右大势至
- **接引像**—阿弥陀前伸右手,迎接往生者
- **变相图**—敦煌壁画"净土变"描绘极乐世界七宝庄严
- **藏传形态**—红色身,主西方莲花部
- **日本形态**—Amida佛立像

## 八、藏传/日本形态

**藏传密宗**:
- **五方五佛**之一—**红色阿弥陀**主**西方莲花部**
- **无量寿佛(Amitayus)** 是长寿仪轨核心

**日本净土宗与净土真宗**:
- **法然**(1133-1212)开创日本净土宗
- **亲鸾**(1173-1263)开创**净土真宗**—"恶人正机说"极端普世化
- 日语作**Amida**,是日本平民佛教主流

## 九、跨文化对应

- **对比琐罗亚斯德 Ahura Mazda**:两者皆为"光"的至高神,阿弥陀"无量光"与Ohrmazd"智慧光"结构近似
- **对比希伯来 Heaven / 基督教 Paradise**:西方极乐与天堂皆为死后理想国
- **对比伊斯兰 Jannah**:皆为多层次乐土,九品往生与七层天堂结构类同
- **与道教三清境**:皆超越性乐土,但极乐纯属佛土,三清境属道境
- **与太上老君**:两者皆为救度性宗教核心,但阿弥陀外求净土,老君强调即身修道

## 十、六字洪名的普世意义

**"南无阿弥陀佛"**是华人最普遍知晓的宗教用语:
- 见面招呼(僧人)
- 感叹惊讶
- 祈福保佑
- 临终诵念
- 超度祭祀

即使**不信佛教的华人**也普遍知晓此句—这是净土宗**最成功的文化输出**。

## 十一、当代影响

- 全球华人佛教社区**净土宗为主流**
- **净土念佛机**电子诵佛设备普及
- 台湾**佛光山、慈济、法鼓山、中台山**皆重视念佛
- **临终关怀**多以念佛为核心
- **Sabino (2019)** 论巴西Chen Tien寺阿弥陀信仰在拉美华人的传承
- **Vojtíšek (2022)** 论捷克越南移民阿弥陀信仰的社区功能
