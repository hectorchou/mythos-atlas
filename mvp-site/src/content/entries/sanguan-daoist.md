# 三官大帝 · 天官地官水官

## 一、身份与名号

**三官大帝** 是道教最早成体系的执政神,由三位大帝构成:
- **天官** 全称"**上元一品赐福天官紫微大帝**"
- **地官** 全称"**中元二品赦罪地官清虚大帝**"
- **水官** 全称"**下元三品解厄水官洞阴大帝**"

亦称"**三元大帝**"或民间俗称"**三界公**"。**锺国发(2005)** 指出,三官是宋代道教神界官僚体系(天/地/水三大系列)的最高执政层,位阶仅次于三清和玉皇。

## 二、起源—东汉天师道"三官手书"

**Huang (2015)** 与 **Verellen (2004)** 一致确认三官信仰起源于**东汉张陵天师道**:

《三国志 · 张鲁传》裴松之注引《典略》记载"**三官手书**":信徒患病时,由道士写三份忏悔文,分别:
- **投于山**(呈天官)
- **埋于地**(呈地官)
- **沉于水**(呈水官)

三官阅读后,或赦罪治病,或惩戒不悛。这是**华夏最早成体系的忏悔—赦罪仪式**,比佛教忏悔法早出现。**Verellen (2004)** 论《赤松子章历》系统化了向三官上奏的仪式细节,是天师道教团运作的核心机制。

## 三、宇宙论定位

三官对应**天—地—水**三界,构成道教三元宇宙:
- **天**(阳)—掌命籍功过
- **地**(阴)—掌鬼魂罪福
- **水**(玄)—掌灾厄消解

三者构成宇宙运行的三个维度。**Huang (2001)** 论证南宋道教绘画中三官必以**上中下三段式**构图排列,反映其宇宙论层级。

## 四、三元节日体系

**《太上三元赐福赦罪解厄消灾延生保命妙经》**规定:

| 节日 | 日期 | 主管 | 功能 |
|------|------|------|------|
| **上元节** | 正月十五 | 天官 | 赐福 |
| **中元节** | 七月十五 | 地官 | 赦罪 |
| **下元节** | 十月十五 | 水官 | 解厄 |

- **上元节**—与元宵节合流,张灯庆福
- **中元节**—与佛教盂兰盆节合流,超度亡魂,是华人祭祖大节
- **下元节**—虽较冷清,但道教内部仍隆重设醮

**Fan (2021)** 详细分析三元节仪式,是道教年度周期的骨架。

## 五、五种历史形态

**雷伟平(2023)** 追溯三官身份的历史演变,归纳出**五种形态**:

1. **天地水三官**(主流)—抽象三界执政神,清代遍布全国及东亚东南亚
2. **陈子椿三子**—民间将陈子椿三子附会为三官
3. **唐宏、葛雍、周武**—历史人物人格化
4. **茅盈、茅衷、茅固**—茅山派尊三茅真君为三官
5. **尧、舜、禹**—上古圣王作为三官化身

第一种形态是官方与主流道教定型,后四种为地方特色。

## 六、图像学

**Huang (2001)** 与 **Gesterkamp (2011)** 详细研究三官图像:
- **天官**—戴天平冠、着龙袍、持玉笏,神情端庄
- **地官**—戴通天冠、着朝服、持云板,面色略赤
- **水官**—戴通天冠、着水波袍、持水府符,常伴龙鱼
- 三官呈品字或横列排列,上中下三段式为南宋典型

台湾"三界公炉"通常悬挂于神明厅正中横梁下,是华人家庭最重要的敬神象征之一。

## 七、与其他神祇对比

- **对比希腊三神**(Zeus/Poseidon/Hades):功能对应但道教三官为文官执政,希腊三神为战神/海王/冥王
- **对比印度三神**(Brahma/Vishnu/Shiva):三分宇宙结构对应,但印度三神主创造/维持/毁灭,三官主赐福/赦罪/解厄
- **对比琐罗亚斯德 Amesha Spentas**:结构性对应(高神下的多位辅佐执政神)
- **对比希伯来天使七长**:皆为最高神下的分工执政层

## 八、当代信仰

- **台湾**"三界公"是家庭神明厅核心供奉之一,与关帝、观音、玉皇并列
- **福建、广东、香港**道教庙宇普遍设三官殿
- **东南亚华人**(马来西亚、新加坡、泰国、越南)延续三官信仰
- **中元节普渡**是华人年度最盛大祭祖活动,虽已与佛教融合但道教内涵不失
- **雷伟平(2023)** 指出三官信仰是"中华文化多元一体性"的典型代表

## 九、道教内部功能

三官在道教斋醮仪式中占核心位置:
- **炼度**—通过三官超度亡魂
- **拜表**—向三官上奏忏悔文
- **朝真**—三元节朝拜三官

**Verellen (2004)** 指出,这一仪式传统未经中断地从东汉延续至今,是道教教团最古老且最活跃的仪式核心。
