## 描述

Itzamna 是**尤卡坦玛雅的最高神**——他是**创造者、文字发明者、历法制定者、医药之神、祭司守护神、王权原型**的**六职合一**神格。在玛雅文明中，**文字与知识不是人类发明，而是神明的赐予**——这一神学立场深刻塑造了玛雅祭司阶层的社会地位与玛雅王权的合法性基础。

**Itzamna 与《波波尔·乌》的 Gucumatz-Huracán 神谱是玛雅内部两大分支的最高神对应**：

- **尤卡坦玛雅**：**Itzamna**（单一至高神）
- **基切玛雅**：**[Gucumatz](/entries/kukulkan-mesoamerica) + [Huracán](/entries/huracan-maya)** （双元创造者）

理解Itzamna就是理解玛雅内部多样性的宗教基础，也是补足[《波波尔·乌》母题词条](/entries/popol-vuh-corpus)缺失的**尤卡坦视角**。

## 名字与图像

### 词源

**Itzamnaaj / Itzamna** = "**itz**（神圣液体/露水/树液）"+ "**am**（可能是'蜥蜴'或'长者'）" + "**naaj**（房屋/家）"

字面可能意为：
- **"神圣液体之家"**（天空作为神圣液体的容器）
- **"蜥蜴屋"**（天空作为覆盖大地的巨大蜥蜴）

J. Eric S. Thompson 在《The Cosmological Symbolism of the Iguana House》中论证：**Itzamna 是"天空作为鬣蜥的宇宙论"的人格化**——古玛雅将天空想象为四条鬣蜥（每条对应一个方位）联合覆盖大地，Itzamna 是这一宇宙结构的至高神。

### 图像特征

**古典期"神D"** = 后古典期 Itzamna 的图像标识：

| 特征 | 含义 |
|------|------|
| **老年男子形象** | 智慧的年长神 |
| **罗马鼻/大鹰钩鼻** | 权威象征 |
| **方形眼睛** | 神性标志 |
| **无牙或牙齿磨平** | 极高年龄 |
| **头饰有太阳/天空符号** | 与天空绑定 |
| **有时有蜥蜴/爬行动物元素** | 鬣蜥屋宇宙论 |
| **手持毛笔或书本** | 文字之神 |
| **主持祭祀场景** | 祭司之神 |

**Karl Taube 在《Itzamna: The God of Gods》中系统识别**——这些视觉标识贯穿古典期陶器、后古典期抄本、殖民时代文献，构成**跨1500年图像连续性**的证据链。

## 六大职能

### 一、创造者与最高神

**Landa《Relación》** 记载：

> **他们说他是伟大的神，第一位……他被称为**Itzamna**，是所有神明中最伟大的。**

Itzamna 是尤卡坦玛雅神系的**顶峰**——所有其他神明（包括Chaac雨神、Ixchel月神、Bolon Dz'acab雷神等）都在他之下。**这与基切玛雅的双元创造者（Gucumatz+Huracán）形成鲜明结构差异**。

### 二、文字发明者：玛雅祭司的合法性基础

Landa 明确记载：**Itzamna 是玛雅象形文字的发明者**。

**这一神学立场的政治意义极其深远**：

- **文字来自神明** → 不是所有人都能使用
- **祭司是文字的合法传承者** → 祭司阶层的合法性
- **书写=神圣行为** → 抄本被视为神圣物品
- **Landa 焚书是宇宙秩序的破坏** → 玛雅人视西班牙征服为神学灾难

Michael D. Coe 在《Itzamná and the Origin of Writing》中论证：**玛雅祭司阶层的合法性完全建立在Itzamna神学之上**——祭司自视为**Itzamna的直接传承者**，掌握文字即掌握与神明的直接沟通渠道。

### 三、历法制定者

- **卓尔金历（Tzolk'in，260日圣历）**
- **哈布历（Haab，365日太阳历）**
- **长纪历（Long Count，5125年宇宙周期）**

三大玛雅历法均被视为 Itzamna 的赐予。**玛雅历法的天文精度是前哥伦布世界最高的**——远超同时代欧洲。这一精度背后的神学基础：**历法不是人类发明，是宇宙秩序的记录**，Itzamna 作为最高神的记录被祭司抄录。

### 四、医药之神

**Ritual of the Bacabs**（18世纪尤卡坦玛雅仪式咒语集）反复呼唤Itzamna治愈疾病。玛雅医药实践包括：
- **药草学**（数百种植物药）
- **精神性疗法**（咒语、放血）
- **助产术**（Ixchel辅助）

**Itzamna 是这一完整医药体系的守护神**。有趣的是：**Landa在破坏玛雅文化的同时，也记录了大量玛雅医药知识**——因为他和其他传教士从中受益。

### 五、王权原型

**Copán Stela H**（730年）**明确记载18 Rabbit王身着Itzamna装扮举行仪式**。玛雅王的加冕仪式中：
- 王戴Itzamna特征的**罗马鼻面具**
- 手持**神圣文字卷轴**——象征王也是Itzamna的传承者
- **书写=王权** —— 只有王能命令使用文字

**这与"[双子英雄](/entries/hero-twins-maya)-王权"** 和 **"[玉米神](/entries/maize-god-maya)-王权"** 神学并列，构成玛雅王权的**三重神学基础**：
- 王 = Hunahpu 化身（战争/仪式）
- 王 = 玉米神化身（农业/循环）
- 王 = Itzamna 化身（知识/文字/王权）

### 六、白日太阳神 Kinich Ahau

**Coe & Kerr 论证**：Itzamna 有一个**白日形态 Kinich Ahau（"太阳眼之王"）**——他不仅是创造者，还是**白日的太阳神**。

- 夜间形态：Itzamna（老年智者）
- 白日形态：Kinich Ahau（青年太阳王）
- 二者是**同一神明的两个时相**

**这一"神明的时相变化"** 是玛雅神学的独特之处——**神性不是静态存在，而是时间性的循环**。

## 神谱结构：尤卡坦 vs 基切

**尤卡坦玛雅与基切玛雅（《波波尔·乌》所属）的神谱结构存在关键差异**：

### 尤卡坦：单一至高神 + 多下属神

```
        Itzamna（最高神/单一至高）
              │
     ┌────────┼──────────┬───────────┐
     │        │          │           │
   Chaac   Ixchel    Bolon Dz'acab  K'inich Ahau
   （雨神）（月神/助产）（雷神）   （太阳神=Itzamna白日形态）
     │
   Bacabs（四方支柱神）
```

### 基切：双元创造者 + 后续神系

```
        Tepeu ↔ Gucumatz + Huracán（双元协作创世）
              │
     ┌────────┼──────────┐
     │        │          │
    Hun     双子英雄    Xibalba九主
    Hunahpu  Hunahpu+  Hun Camé等
    （父辈） Xbalanque
```

**这一结构差异反映了玛雅内部不同分支的神学传统**：

- **尤卡坦低地传统**：**父权型至高神**，可能受特奥蒂瓦坎影响
- **基切高地传统**：**双元协作创世**，可能保留更古老的层次

**两者不是对立，而是玛雅内部丰富多样性的表达**。

## Diego de Landa 悖论

**方济各会主教 Diego de Landa 是玛雅史上最矛盾的人物**：

### 破坏者面向

**1562年7月在Maní镇**，Landa主持"审判信仰"仪式：
- **焚烧几乎所有玛雅象形文字抄本**（估计数千件）
- **处决拒绝改信的玛雅贵族**
- **销毁玛雅神像**

**这一事件是人类文化史最大灾难之一**——**如果那批抄本保留下来，我们对玛雅文明的理解会完全不同**。今天只有4份古玛雅抄本幸存：Dresden、Madrid、Paris、Grolier。

### 记录者面向

**吊诡的是**——Landa 在破坏玛雅文化的同时，也**详细记录了大量玛雅知识**：

- **《Relación de las cosas de Yucatán》（1566）**：**是玛雅信仰、历法、字母、社会结构的最详细殖民时代记录**
- 他与玛雅贵族合作**部分破译玛雅象形字母**（虽然错误理解为字母，实际是音节文字）
- **他记录了Itzamna作为最高神的信仰**

Landa 在**破坏与保存之间**的悖论使他成为**殖民主义研究的经典样本**——**同一个人可以既是文化屠夫，又是文化档案员**。

**没有 Landa，我们对尤卡坦玛雅信仰的知识会大幅减少**——但**没有 Landa，玛雅象形文字文献会保留几千倍**。这是玛雅学最沉重的历史悖论。

## Landa 焚书的后果与幸存证据链

Landa 焚书使玛雅象形文字文献几乎完全消失。**理解玛雅需要从间接证据重建**：

### 三大证据源

**1. 幸存的4份抄本**：Dresden / Madrid / Paris / Grolier
- 全部是后古典期（1200-1500年）
- 主要内容：天文/历法/仪式/预言
- 神话叙事内容有限

**2. 大量石刻铭文**：数千件古典期玛雅王朝铭文
- 主要记载王朝历史与仪式
- 神明名字反复出现
- **1970年代以来象形文字破译使这些铭文可读**

**3. 殖民时代文本**：
- 《波波尔·乌》（1554-1558）——基切
- 《Chilam Balam de Chumayel》——尤卡坦
- 《Anales de los Cakchiqueles》——Kaqchikel
- Landa《Relación》——尤卡坦

**Itzamna 主要通过殖民时代文本 + 图像证据得以重建**——比《波波尔·乌》有直接文本的双子英雄叙事更间接。

## 现代化：玛雅原住民复兴

Itzamna 信仰在殖民后的转化：

### 与天主教融合

- Rigoberta Menchú 等原住民运动领袖将其纳入原住民权利话语

## 学术意义

1. **玛雅内部神谱多样性的核心样本**：与基切《波波尔·乌》双元创世形成对照
2. **世界"文字神圣起源"神学的完整案例**：与奥丁、Thoth、伏羲同属谱系
3. **玛雅祭司阶层合法性的神学基础**：文字=神明的赐予→祭司=神明的代言人
4. **殖民主义悖论的经典样本**：Landa 破坏与记录并存
5. **神明时相变化的独特神学**：Itzamna（老年智者）↔ Kinich Ahau（青年太阳王）
6. **1500年图像连续性**：古典期神D到后古典期Itzamna的完整证据链
7. **玛雅王权三重神学基础的核心**：与双子英雄、玉米神并列

## 在《波波尔·乌》谱系中的位置

Itzamna 补足了《波波尔·乌》母题伞形词条的**尤卡坦维度**——[《波波尔·乌》](/entries/popol-vuh-corpus)是基切分支的圣书，Itzamna 是尤卡坦分支的最高神。二者共同构成**玛雅文明神学的完整版图**。理解玛雅需要同时理解两大分支——**只知道《波波尔·乌》而不知道Itzamna，就像只读《埃达》而不知道日耳曼大陆宗教一样片面**。
