# 关圣帝君 · 关公与忠义武神

## 一、身份与地位

**关羽**(160-220),字**云长**,后世尊称**关公、关帝、关圣帝君、武圣**。是**华人最普及的民间信仰神明**,**儒释道三教共尊**:
- **儒教**尊为"**武圣**",与孔子"**文圣**"并列
- **佛教**尊为"**伽蓝菩萨**"(护法神)
- **道教**尊为"**关圣帝君**"(帝级神明)

**Duara (1988)** 提出著名的"**叠加符号(Superscribing Symbols)**"理论—关公是不同群体(朝廷/文人/商人/军人/黑社会/佛教/道教)在同一神像上叠加各自意义的典型案例。

## 二、历史关羽

**陈寿《三国志 · 关羽传》**记载:
- **160年**生河东**解良**(今山西运城)
- 因触法亡命奔涿郡
- 与**刘备、张飞**"恩若兄弟"(《三国演义》"桃园结义"为文学建构)
- 忠义无双,"策马刺良于万众之中"—斩袁绍大将颜良
- **建安十九年(214)**镇守荆州
- **建安二十四年(219)**水淹七军,威震华夏
- **220年正月**被孙权部将擒杀于**临沮**

历史关羽功业彪炳但仍属地方将领级别,其后世神化经历漫长过程。

## 三、从饥鬼到国神—神格化过程

**ter Haar** 详细追溯关公信仰演变:

**第一阶段:荆州厉鬼(220-750)**
- 关羽被杀于临沮,首级送洛阳,身葬当阳
- 当地百姓因其冤死立庙祭祀,防其"厉鬼"作祟
- 此阶段关公信仰局限于荆襄

**第二阶段:佛教整合(750-960)**
- 8世纪**天台宗智顗**大师在玉泉山见关羽显圣
- 佛教将关公吸纳为**伽蓝菩萨**(护法神)
- 关公信仰获得跨地域宗教框架

**第三阶段:道教纳入与朝廷加封(960-1400)**
- 宋徽宗**1102-1128年**先后封"忠惠公""崇宁真君""昭烈武安王""义勇武安王"
- 关公进入道教神谱

**第四阶段:明清帝化(1400-1911)**
- **明万历1614年**封"**三界伏魔大帝神威远震天尊关圣帝君**"
- **清顺治**封"**忠义神武关圣大帝**"
- **清光绪**加封至**26字**帝号:"忠义神武灵佑仁勇威显护国保民精诚绥靖翊赞宣德关圣大帝"
- 与孔子并列**国家祭祀**核心

## 四、《三国演义》文学神化

**罗贯中《三国演义》**(约1370年)将关公塑为完美英雄:
- **桃园结义**—刘关张兄弟情义模板
- **温酒斩华雄**—一战成名
- **过五关斩六将**—千里寻兄的忠义
- **华容道义释曹操**—宁负君不负恩的义
- **单刀赴会、水淹七军**—神勇无匹
- **败走麦城**—悲剧英雄结局

这一文学形象超越历史,成为**华人道德理想**的具象化。

## 五、图像学

**关公典型形象**(南宋定型):
- **红脸美髯**(五绺长须)
- **丹凤眼、卧蚕眉**
- **绿袍金甲**
- **手持青龙偃月刀**(重82斤,历史无据)
- **胯下赤兔马**
- **周仓**(捧刀)、**关平**(捧印)侍立左右
- **常读《春秋》**—体现"义"的象征

**Yang Zheng (2005)** 研究**洛阳关林**(关公首级葬地),当地信众认为关公首级至今仍在关林,是关帝信仰最重要的**首级崇拜**中心。

## 六、多重神格叠加

**Duara (1988)** 论关公"叠加符号"包括:

| 群体 | 关公的意义 |
|------|----------|
| **朝廷** | 忠君护国的模范 |
| **儒家文人** | 熟读《春秋》的儒将 |
| **军人** | 战神,武运保护 |
| **商人** | 财神(诚信/义气) |
| **佛教** | 伽蓝护法菩萨 |
| **道教** | 关圣帝君,伏魔天尊 |
| **黑社会** | 义气,兄弟盟约 |
| **警察** | 惩恶扬善的正义 |

不同群体在同一关帝像前烧香,各自叠加所需意义—这是华人信仰**实用性、多义性**的典型体现。

## 七、商人财神—独特神职

明清以来,关公成为**商人财神**,与**赵公明、比干、范蠡**并列华人四大财神。原因:
- 关公"重义轻利"—反成信义之神
- 明清晋商崛起,山西是关公故乡,晋商到处建关帝庙
- 商业需要"诚信"作为信用担保
- 结拜"义气"是商业合作的道德基础

至今**华人商铺、餐馆**普遍供奉关公,是华人商业文化的核心象征。

## 八、全球华人信仰传播

- **香港**警察局、廉政公署皆供关公
- **台湾**关帝庙数千座
- **东南亚**华人社区(马、新、印、泰、越)必有关帝庙
- **日本**横滨、神户、长崎中华街皆供关公
- **韩国**首尔东庙(1601年建)为壬辰倭乱后明军所建
- **Lee (2020)** 论朝鲜兴天寺庙神画显示韩国佛寺对关公的本土化接受
- **欧美唐人街**普遍设关帝庙

## 九、跨文化对应

- **对比希腊 Ares**:两者皆为战神,但关公强调"义"而非纯粹武力
- **对比北欧 Tyr**:两者皆为"公正与誓约"守护神
- **对比印度 Skanda**:两者皆为战神+护法双重
- **对比日本 Hachiman**(八幡神):两者皆为历史武人神化,关公文学色彩更浓
- **与佛教毘沙門天**:两者皆为战神+财神双职

## 十、当代影响

- **香港黑社会入会**须"斩鸡头拜关公"
- **警察局**同样供关公—矛盾却互不冲突,体现"叠加符号"理论
- **中国大陆**近年恢复关帝文化研究,山西运城解州关帝庙、湖北当阳关陵、河南洛阳关林三大祖庭
- **金庸/古龙**武侠小说频繁引用关公忠义精神
- **Zavidovskaya (2023)** 综述海外汉学关公研究的持续活跃
