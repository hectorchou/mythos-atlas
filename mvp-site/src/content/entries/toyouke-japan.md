# 丰受大神 · 伊势外宫的穀物与产业女神

## 一、名号与身份

**丰受大神(Toyouke-Ōmikami, 豊受大御神)** 是**日本伊势神宫外宫(下宫)** 主祭神,**穀物・饮食・衣食住・产业女神**,与内宫**天照大御神**并立构成**日本神道最高圣所双祭结构**。

**Teeuwen (1996) 权威 *Watarai Shinto*** 与 **Ponsonby-Fane (2014)** 综合:

**名字含义**:
- **"豊(toyo)"** ——**丰盛、丰饶**
- **"受(uke/ukeru)"** ——**受纳、接受**
- 全名义"**丰盛的受纳者**"或"**丰盛食物之神**"
- 别称:**豊受媛神(Toyouke-hime-no-Kami)**、**御饌都神(Miketsu-no-Kami, 食物之神)**、**度会大神**

**核心身份**:
- **穀物神**——五穀主神
- **产业神**——衣食住之神,商业繁荣守护
- **外宫大神**——伊势神宫**外宫(Geku)** 主祭神
- **天照御饌都神**——负责为天照准备日常饮食

**Rots (2014) 现代伊势神宫官方阐释**:"**丰受负责照顾天照的饮食**"——反映**当代神道自我定位**的神学简化。

## 二、《古事记》与《日本书纪》记载

**《古事记》记载**:
- **和久産巣日神(Wakumusubi)** 之子
- 名**豊宇気毘売神(Toyouke-hime-no-Kami)**
- 出场极简

**《日本书纪》记载**:
- 名**豊受媛命**
- 与保食神(Ukemochi)相关联
- **多本传结构**下多种记述

**Teeuwen (1996)** 关键论:**记纪中丰受地位远低于后世**——**中世纪渡会家的神学建构**才将其抬升到**与天照同格**的最高地位。

## 三、雄略天皇勧请起源

**Ponsonby-Fane (2014)** 引 **《止由気宮儀式帳》**(平安初期804年):

**传说时代**:**雄略天皇22年(478)**

**核心叙事**:
- **天照大御神**托梦雄略天皇
- 神谕:"**一处孤食难安,请为余招丹波国比治真名井之等由気大神**"("**一処坐すのみは苦し、丹波比治真名井から等由気大神を我が近くに祀れ**")
- **等由気(Toyuke)** 即**丰受**的古音变体

**勧请过程**:
- 从**丹波国比治真名井原**(今京都府福知山市大江町)勧请
- **勧请路径**：丹波→山城→大和→伊势度会郡
- **山田原(Yamada-hara)** ——今三重县伊势市——为最终奉祀地
- 建**度会宫(Watarai-no-Miya)** 即**外宫(Geku)**
- 与**内宫皇大神宫**(约478年前迁至现址)成**双祭结构**

**Teeuwen (2006)** 论:雄略天皇22年勧请**可能非史实**,而是**平安时代**对**丰受与丹波地方神合并**的神学化叙事——**丰受原为丹波比治真名井的地方农业神**,后被抬升为**国家级伊势外宫大神**。

## 四、伊势神宫的双宫结构

**Djokoto (2013) 与 Vegas & Mileto (2003)**:

**伊势神宫**由**内宫(Naiku)** 与**外宫(Geku)** 两大主要神社构成:

| 宫 | 主祭神 | 位置 | 神格 |
|----|-------|-----|------|
| **内宫(皇大神宫)** | **天照大御神** | 五十铃川畔 | **皇祖神** |
| **外宫(豊受大神宫)** | **豊受大御神** | 度会郡山田原 | **穀物・食物神** |
| **距离** | 约4公里 | | |

**外宫先祭制度(Geku-sensai)**:
- **每祭必先外宫,后内宫**
- **食物神先受祭**,方能奉侍天照
- 起源于**丰受为天照准备饮食**的神学
- **神馔** **日別朝夕大御饌祭(Higoto Asayū Ōmike-sai)** 每日早晚2次日供,自平安以来**未曾中断**

**建筑样式**:
- **唯一神明造(Yuiitsu Shinmei-zuku)** ——只用于伊势神宫的**神圣建筑样式**
- **千木(chigi)** 与**堅魚木(katsuogi)** 装饰
- **外宫千木**:**外削(平削)** ——象征男神(神学争议)
- **内宫千木**:**内削(平削)** ——象征女神

**式年迁宫(Shikinen Sengu)**:
- **每20年一次**重建两宫全部建筑
- **持续至今**——**2013年为第62次**
- **2033年将迎第63次**
- **世界最长连续宗教建筑传统**——**1300余年不间断**
- **建筑技艺**通过重建代代相传

**McKeracher (2014)** 论式年迁宫的**"设计毁灭"** 哲学——**新木与旧木的循环**是**神道洁净观**的建筑体现。

## 五、渡会神道:中世纪神学革命

**Teeuwen (1996) 关键专著《Watarai Shinto》**:

**渡会家(Watarai-ke)** 为**伊势外宫世袭祭司家族**——自古掌管外宫祭祀。

**背景**:**镰仓时代(13世纪)**,内宫**荒木田家**(掌天照)政治势力强于外宫渡会家。**渡会家为提升地位**,发起**神学革命**。

**核心创造:《神道五部书》**
- **《宝基本纪》**
- **《倭姫命世纪》**
- **《天照坐伊势二所皇太神宫御镇座次第记》**
- **《伊势二所皇太神宫御镇座传记》**
- **《豊受皇太神御镇座本纪》**

**主编者**:**度会行忠**、**度会常良**、**度会家行** 等13-14世纪渡会祠官。

**神学要点**:
1. **丰受即国常立神(Kunitokotachi)** ——**造化三神**之一,**神代七代**之首,**日本最本源之神**
2. **外宫大神比内宫大神更本源**——**颠覆内宫为主的传统**
3. **心御柱(Shin no Mihashira)** ——外宫神殿中心埋柱,象征**天地未分之元神**
4. **清明诚心(seimei-shinshin)** ——**伦理化神道**核心
5. **本地垂迹说**中丰受对应**大日如来**或**如意宝珠**

**Morley (2019)** 论此为**祭司政治竞争的神学化**——**外宫因经济衰退**需通过**理论创新**吸引朝廷与将军家关注。

**Kuroda (1981)** 关键评价:**渡会神道是中世神道最重要理论体系**——**打破神佛习合**,**开启日本神道独立神学化**,**为江户国学、明治国家神道铺路**。

## 六、造化三神与丰受

**渡会革命的核心**:将丰受与**造化三神**关联。

**造化三神**(Zōka Sanshin):
- **天御中主神(Ame-no-Minakanushi)**
- **高皇産霊神(Takami-musubi)**
- **神皇産霊神(Kami-musubi)**

**神代七代**(Kamiyo Nanadai)第一代:
- **国常立神(Kunitokotachi)**

**渡会家论证**:
- 丰受 = **和久産巣日神之子**(《古事记》)
- 和久産巣日 与 **神皇産霊** 相关
- **产霊(musubi)** 神系为**创造原动力**
- 故丰受 = 造化神谱系
- 更进一步 = **国常立神本身**(**神代最初之神**)

**神学效果**:**外宫大神从食物神跃升为宇宙本源神**——**天照仅为其显化**。

## 七、江户国学与丰受神学的反动

**Tajiri (1998)** 论:

**江户时代(1603-1868)** **国学派**:
- **本居宣长(Motoori Norinaga)** *《古事记传》*
- **平田笃胤(Hirata Atsutane)** *《古史成文》*

**批评渡会革命**:
- 渡会家**过度佛教化**(本地垂迹说)
- **中世神学附会**背离记纪原义
- 应**复归古事记本源**

**本居宣长立场**:
- **丰受即食物神**——**记纪原意**
- **天照才是最高神**——**皇祖神地位**
- **反对渡会家颠覆内宫**

**平田笃胤复古神道**:
- **进一步简化神学**
- **强化天皇天照系正统**
- **为明治国家神道铺路**

## 八、明治废渡会与国家神道

**明治维新(1868)**:
- **神佛分离令**——废除神佛习合
- **废除渡会家世袭祭司职**
- **伊势神宫收归国家神道**
- **神职人员由政府任命**
- **式年迁宫由国家财政支持**

**明治**将丰受**重新定位**:
- **食物神+产业神**——服务国家现代化
- **护国神道系统**中重要一环
- **国民精神动员**核心

**战前昭和**:**皇道大祭**中丰受与天照同为**国家最高神**。

## 九、战后神社本厅体制

**Rots (2014)** 论:

**1945年战后**:
- **神道指令(1945.12.15)** ——GHQ强制**政教分离**
- 伊势神宫**神格降为宗教法人**
- **神社本厅(Jinja Honcho)** 成立(1946)
- **伊势神宫为总本宫**

**丰受当代信仰**:
- **产业繁荣**、**商业发达**、**衣食住安泰**核心祈祷对象
- **企业家、渔民、农民**主要朝拜者
- **每日日別朝夕大御饌祭**继续
- **全国摄末社约2万余处**

**式年迁宫**继续:
- **2013年第62次**——费用约550亿日元
- **2033年第63次**预定

## 十、神馔:日本饮食文化原型

**《神馔中蕴含的日本饮食文化》**(2011中文)与 **Andrei (2022)**:

**日別朝夕大御饌祭**:
- **每日早晨(朝之神馔)、傍晚(夕之神馔)** 献食
- **持续1500年未曾中断**——**世界最长连续献食传统**

**神馔内容**:
- **神米(Shinsen)** ——伊势神宫米田专种
- **神酒**——白酒、黒酒、清酒、醴酒
- **海产**:鲍、鱼、海苔、贝类
- **山产**:野菜、蕈类
- **水果**:柑橘、柿子、栗子
- **盐、水、乾物**
